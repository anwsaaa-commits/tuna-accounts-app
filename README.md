# متجر تونة بلس — Tuna Plus

تطبيق Flutter عربي لإدارة بيع التونة بالكيلو، العملاء، الفواتير، البيع النقدي والآجل، التحصيلات، أرصدة العملاء، والتقارير بصيغة PDF.

## البناء
يتم البناء تلقائياً عبر GitHub Actions عند الدفع إلى الفرع main أو يدوياً من تبويب Actions.

## الحالة
نُقلت ملفات التطبيق الأساسية من مشروع التطوير السابق. يجري حالياً تدقيق أخطاء التحليل والاختبارات قبل اعتماد APK.
